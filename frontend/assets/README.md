Los afiches son composiciones HTML/CSS para películas ficticias del mock. No son afiches oficiales. Títulos, sinopsis, duraciones y clasificaciones pertenecen a la demostración.

Referencias consultadas para la dirección visual: [Cine Colombia](https://www.cinecolombia.com/) y [Curzon](https://www.curzon.com/). Se tomó como guía la presentación de cartelera y películas; no se usaron sus logotipos ni su código.
