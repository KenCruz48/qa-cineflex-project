# Sustentación: máximo 3 minutos

Ensayar con el equipo y repartir las intervenciones entre sus integrantes. Mostrar código y una ejecución real. No presentar esta guía como evidencia de un video ya grabado.

| Tiempo | Demostración |
|---|---|
| 0:00-0:25 | Objetivo de CineFlex y carpetas backend, frontend, API, UI y performance. |
| 0:25-0:55 | Express, Helmet/Morgan, SQLite y stub. Explicar Top-Down y por qué un pago rechazado no ocupa el asiento. |
| 0:55-1:25 | Ejecutar `npm run test:api` con el servidor activo. Mostrar captura del JWT, SLA y rechazo 402. |
| 1:25-2:05 | Mostrar LoginPage/CarteleraPage/ReservaPage y las aserciones separadas en test_suite.js. Ejecutar `npm run test:ui`. |
| 2:05-2:35 | Abrir el JMX: 500 usuarios, ramp-up 15 s, JWT y consulta de asientos. Mostrar Summary Report real y sus métricas. |
| 2:35-2:55 | Abrir GitHub Actions y explicar el fallo de CI y el check requerido para proteger main. |
| 2:55-3:00 | Indicar ubicación de estrategia y resultados; cerrar la demostración. |

Preparar terminales y pestañas antes de grabar. Publicar el video con acceso público y pegar el enlace al inicio del README. No usar datos personales ni tarjetas reales.
